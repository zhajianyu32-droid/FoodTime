🍳 项目定位

FoodTime 是为「独居青年」设计的吃饭决策助手，用算法 + LLM 解决 「今天吃什么」 的人生难题。

🍳 Cook Mode 🛵 Order Mode 📖 美食日记 🧠 偏好引擎 🃏 美食运势 🛒 购物单
