- 【可复用技法｜Ardot 装饰性矢量图】① 整张装饰图用「单个 type:"frame" + svg 字符串」插入 → 1 个 op 顶几十个矢量节点，不要逐个建 node；但 svg 子节点颜色无法单独 U() 修改，改色只能 D() 删掉再重插（重插后会跑到父节点最上层，若有叠在上面的文字节点需一并 D 掉后按顺序重建）。② 卡背等需要叠字（如印章「食」）时，父容器设 layout:"none" + cornerRadius + clipsContent，再叠一个 x/y/width/height 固定 + textAlignHorizontal/Vertical CENTER 的文字节点。③ 圆角卡片的 SVG frame 必须显式 fills:[]，否则矩形 rx 圆角处会漏出 frame 的默认白底。④ SVG 里用 C 三次贝塞尔代替 A 圆弧命令更保险。⑤ 用 fill=背景色 的实心圆可以做「遮罩」抠出月牙，但被遮的圆只能用描边时结果会是 C 形而非月牙——真月牙要用双曲线 path。
- 【坑｜Ardot SVG 解析「degenerate geometry」】batch_edit 的 svg 字符串会让整个 Insert 失败（报 "parsed to degenerate geometry: vector is empty (0×0) or out of frame bounds"）的两个确认雷区：① `stroke-dasharray="0.01 6"` 这种零长 dash 做点线（圆上的 0.01 dash 反而没事，<line>/<path> 上会炸）→ 改用 "1.5 6" 这类非零 dash + stroke-linecap:"round"，视觉上仍是圆点；② 四角用 `<g transform="scale(-1,1)">` 镜像复用同一段 path → 改为写出 4 份绝对坐标的 path，别用 scale 镜像。另注：失败的 Insert 不会创建节点（后续 D() 会报 not found），但同 batch 任一 op 失败会整体回滚、旧的同位置节点会保留，所以「先 D 旧节点再 I 新节点」是安全的原子替换；U() 改 svg 未验证可行，改图一律走 D + I + 重新 U(effects)。
